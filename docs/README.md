Human-facing documentation entry point. Agent-facing rules:

## What this repo is

A standard template for organizing bioinformatics projects
(`../README.md`): reproducibility, clear separation of data and code, and
organized tracking of outputs and execution parameters.

## Directory map

(from `../README.md`)

- `data/raw/` — immutable raw data (read-only); `data/processed/` —
  intermediate cleansed data
- `scripts/` — production source code for data processing and analysis
- `results/` — formatted outputs (final TSV tables, figures) from scripts
  and notebooks
- `logs/` — execution logs generated by scripts
- `config/` — pipeline configuration files (YAML, JSON)
- `docs/` — this documentation folder

## How to run / test

(from `../README.md` Quickstart; dependencies in `../requirements.txt`)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/01_process_data.py --config config/default.yaml
```

No test suite is present in this repository as of this writing.
